# ART DIRECTION

## Position
- **Quiet 35 / Expressive 65:** The UI is quiet, the spatial world is expressive.
- **Editorial 40 / Spatial 60:** Typography is treated like a high-end magazine; the world is vast.
- **Precise 60 / Organic 40:** Sharp edges and geometric logic offset by subtle dust and fracture.
- **Timeless 65 / Trend-aware 35:** Avoiding heavy glassmorphism, aggressive gradients, and current fads in favor of classic cinematic lighting.
- **Restrained 35 / Immersive 65:** One massive effect per scene rather than a dozen small ones.

## Palette
- `--void`: `#050505` (Deepest background)
- `--space`: `#080B12` (Not used purely, replacing with void for the first scene)
- `--bone`: `#F1EFE8` (Primary typography and UI)
- `--muted`: `#A8A8A3` (Metadata and secondary text)
- `--reality`: `#DB2A2A` (MCU Red accent)
- `--legacy`: `#D2B66A` (Gold inheritance color)

*Rule: No pure white, no generic blue glows. Lighting provides color.*

## Typography
- **Display/Headline:** Clean Grotesk (e.g., Helvetica Neue).
- **Memory Fragments:** High-contrast serif (e.g., Georgia).
- **Metadata:** Monospace (e.g., SF Mono).
- *Strict Rule:* No animation on every word. Max two lines for cinematic headlines. Masked line staggers.

## Grid and Corner Language
- 12 column desktop (48-72px outer margin).
- 4 column mobile (20px margin).
- Hard corners (0px) or microscopic radii (2-4px max). No pill buttons. No rounded panels.
